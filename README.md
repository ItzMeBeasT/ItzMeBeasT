## Projects

### 01 · GoodFit

**AI-powered resume ↔ job matching built around the actual job description.**

<a href="https://github.com/ItzMeBeasT/resume-fit-ai">
<img src="https://github.com/ItzMeBeasT/resume-fit-ai/raw/main/docs/screenshots/demo.gif" width="100%" alt="GoodFit demo"/>
</a>

<br/>

**What it does**

Upload a resume + paste a job description → receive a match score, missing skills and prioritised improvements.

**Engineering highlights**

- Structured Gemini JSON output with **Zod validation**
- Server-side score validation and retry handling
- PDF MIME + magic-byte validation
- Rate limiting and privacy-aware processing
- Prompt-injection-aware input handling
- Automated endpoint and schema tests
- MongoDB persistence for analysis results

`React` `Tailwind` `Node.js` `Express` `MongoDB` `Gemini` `Zod`
