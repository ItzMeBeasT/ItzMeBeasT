## 🧭 About Me

I'm a **Computer Engineering student** building toward a career as a **Cloud & DevOps Engineer with security-conscious infrastructure practices**. I care about systems that stay reliable when things scale — not just code that runs once in a demo.

```yaml
role:        Computer Engineering Student
focus:       Cloud Infrastructure · Kubernetes · DevOps Security
currently:   Building a K8s monitoring platform with RBAC, NetworkPolicies & CI validation
learning:    RHCSA → AWS SAA → CCNA → CKA
philosophy:  Depth over breadth — fewer projects, done properly
```

- 🔭 Currently engineering a **Kubernetes monitoring platform** (Prometheus, Grafana, Alertmanager, RBAC, NetworkPolicies, CI-validated manifests)
- 🌱 Working through a certification roadmap: **RHCSA → AWS Solutions Architect Associate → CCNA → CKA**
- 🛠️ Security isn't a side-track for me — it's woven into every infra project (non-root containers, Trivy scanning, least-privilege RBAC)
- ✍️ I write up what I build — see my [Medium](https://medium.com/@regannbis) for project walkthroughs
- 🎯 Aiming for **product-based companies** in Cloud/DevOps — off-campus is the primary track, on-campus is the safety net
